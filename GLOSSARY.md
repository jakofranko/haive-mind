# Haive Mind

A collaborative agent application that runs over SSH. A host sends directives to an AI agent; participants connect via SSH and respond to the agent's prompts. The group's responses are synthesized into one aggregate, which the host edits and sends back to the agent for further processing.

## Language

### Core Roles

**Host**:
The human operator who initiates rounds by sending directives to the agent, decides who should revise, and sends the aggregate. Its participant id is always `host`.
_Avoid_: Operator, controller, admin

**Participant**:
A human who connects via SSH and submits responses to the agent's prompts during a round.
_Avoid_: User, client, attendee, member

**Agent**:
The AI subprocess (invoked via `opencode run`) that processes directives and generates replies. Not a human. Only the hub invokes it.
_Avoid_: Bot, AI, assistant, model

**Synthesizer**:
A one-off `opencode run` with no session context, used only to turn a round's question and responses into a draft. Separate from the Agent.
_Avoid_: Summarizer, aggregator

**Coordinator**:
The session state that sits beside the hub: the transcript, the current round, each participant's responses, and who is flagged. Reacts to hub messages; never invokes the agent.
_Avoid_: Controller, manager, session

### Identity

**SSH username**:
The name a person connects with. Only the participant id is derived from it; nothing else is keyed by it.
_Avoid_: Login, account

**Participant id**:
The stable hub identity of a participant: `Agent-<SSH username>`, or `host` for the host. Keys the participant registry, display names, drafts, statuses and flags, and is decided in one place. Never changes during a session. Carried on responses as `FromID`.
_Avoid_: Name (ambiguous with Display name)

**Display name**:
What people see: chosen on first connect and shown in lists and transcript headers. Carried on messages as `From`. Stored in the hub under the participant id, and changed by renaming the registered participant. Not unique and not stable; never key anything by it.
_Avoid_: Nickname, username, handle

### Messaging

**Directive**:
A message sent by the host to the agent to start or continue a round. Carries `MessageTypeDirective`.
_Avoid_: Prompt, instruction, command, input

**Response**:
A message sent by a participant, in reaction to the agent's reply. Only each participant's latest response in a round is synthesized; earlier ones stay in the transcript. Carries `MessageTypeResponse`.
_Avoid_: Reply, answer, submission, feedback

**Agent Reply**:
A message generated by the agent in response to a directive or aggregate. Appears in the transcript with the agent's name as `From`. Carries `MessageTypeAgentReply`, never `MessageTypeResponse`.
_Avoid_: Agent response, AI response, model output, completion

**Draft**:
The synthesizer's proposed aggregate. Shared with everyone and opened in the host's input for editing. Carries `MessageTypeAggregateDraft`.
_Avoid_: Preview, suggestion

**Aggregate**:
The group's single answer to a round: the host's edited draft, sent to the agent to continue the round. Carries `MessageTypeAggregate`.
_Avoid_: Summary, compilation, combined response

**Aggregate request**:
The host's signal that the round's responses should now be synthesized into a draft. A signal, not content: it is not an Aggregate and never reaches the agent. Carries `MessageTypeAggregateRequest`.
_Avoid_: Aggregate (reserved for the host's edited draft), trigger

**System Message**:
An informational message generated by the hub (errors, exports, connection events). Carries `MessageTypeSystem`.
_Avoid_: Notification, alert, log entry

**Agent Error**:
A failed call to the agent or synthesizer, published with the message to resend so the host can retry. Carries `MessageTypeAgentError`.
_Avoid_: Failure, exception

**Transcript**:
The shared, append-only message history visible to both host and participants. Contains directives, agent replies, responses, drafts, aggregates, and system messages.
_Avoid_: Log, history, chat, conversation, record

### Session Structure

**Round**:
A complete cycle: host sends directive → agent replies → participants respond → host aggregates → agent replies to aggregate. Identified by an incrementing integer owned by the coordinator.
_Avoid_: Turn, cycle, iteration, phase

**Transcript snapshot**:
The recorded conversation sent to one session when it connects, with that participant's last response for the current round, if any. An ordinary message addressed to the connecting participant id, published beside Round state; other sessions ignore it. Carries `MessageTypeTranscriptSnapshot`. Not Round state: it carries the conversation so far, not where the round stands.
_Avoid_: Replay, history sync, Round state

**Round state**:
The coordinator's announcement of the current round and who is flagged. Published whenever either changes and whenever someone connects, so a session that joins late starts correct. It never resets anyone's status. Carries `MessageTypeRoundState`.
_Avoid_: Sync, session state (a bare "snapshot" is ambiguous; the conversation sent on connect is the Transcript snapshot)

**Round change**:
The event that a new round has started. Participants go back to idle. Distinct from Round state, which says where things stand without starting anything. Carries `MessageTypeRoundChange`.
_Avoid_: New round (that is the host's request to start one)

**Session**:
A single SSH connection from a host or participant to the server. Each session runs one TUI (host or participant).
_Avoid_: Connection, meeting, run

**Session client**:
A session's end of the conversation with the hub. It turns what the hub publishes into typed events for the host or participant TUI, and stops when the session ends.
_Avoid_: Listener, subscriber, connection

### Participant State

**Participant Status**:
What a participant is doing in the round. One of: `idle`, `typing` (composing a response), `submitted` (response sent), `disconnected`. Reported by the participant to the hub.
_Avoid_: State, phase, condition

**Flag** (revision request):
The host's decision that a participant should revise their response. Shown to everyone as `revise`. Cleared when that participant resubmits, when the host resolves, or when the round ends. The host decides what is a conflict; the model is never asked to. Raised and withdrawn with `MessageTypeFlag` and `MessageTypeUnflag`; the current set is published in the Round state.
_Avoid_: Conflict, dispute, rejection

**Resolve**:
The host's action that clears every flag at once.
_Avoid_: Approve, dismiss

**Unsent text**:
What a participant has typed but not sent (the hub calls it a "draft" in code: `SetDraft`/`GetDraft`). Stored in the hub by participant id so it survives a disconnect and reconnect.
_Avoid_: Draft (reserved for the aggregate draft), autosave, buffer

### Transport

**Hub**:
The pub/sub bus. Delivers every message to its subscribers in send order, holds the participant registry and unsent text, and is the only thing that invokes the agent and the synthesizer.
_Avoid_: Broker, router, mediator

**Subscription**:
A handler registered with the hub for one or more message types. The hub calls it, in order, from a per-subscriber mailbox.
_Avoid_: Listener, channel, observer
