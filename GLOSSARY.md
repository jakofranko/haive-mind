# Haive Mind

A collaborative agent application that runs over SSH. A host sends directives to an AI agent; participants connect via SSH and respond to the agent's prompts. The host aggregates responses and sends them back to the agent for further processing.

## Language

### Core Roles

**Host**:
The human operator who initiates rounds by sending directives to the agent and aggregates participant responses.
_Avoid_: Operator, controller, admin

**Participant**:
A human who connects via SSH and submits responses to the agent's prompts during a round.
_Avoid_: User, client, attendee, member

**Agent**:
The AI subprocess (invoked via `opencode run`) that processes directives and generates replies. Not a human.
_Avoid_: Bot, AI, assistant, model

### Messaging

**Directive**:
A message sent by the host to the agent to start or continue a round. Carries `MessageTypeDirective`.
_Avoid_: Prompt, instruction, command, input

**Response**:
A message sent by a participant to the agent, in reaction to the agent's reply. Carries `MessageTypeResponse`.
_Avoid_: Reply, answer, submission, feedback

**Agent Reply**:
A message generated by the agent in response to a directive or aggregate. Appears in the transcript with the agent's name as `From`.
_Avoid_: Agent response, AI response, model output, completion

**Aggregate**:
A message composed by the host from participant responses, sent back to the agent to continue the round. Carries `MessageTypeAggregate`.
_Avoid_: Summary, synthesis, compilation, combined response

**System Message**:
An informational message generated by the hub (errors, exports, connection events). Carries `MessageTypeSystem`.
_Avoid_: Notification, alert, log entry

**Transcript**:
The shared, append-only message history visible to both host and participants. Contains directives, agent replies, responses, aggregates, and system messages.
_Avoid_: Log, history, chat, conversation, record

### Session Structure

**Round**:
A complete cycle: host sends directive → agent replies → participants respond → host aggregates → agent replies to aggregate. Identified by an incrementing integer.
_Avoid_: Turn, cycle, iteration, phase

**Session**:
A single SSH connection from a host or participant to the server. Each session runs one TUI (host or participant).
_Avoid_: Connection, meeting, run

### Participant State

**Participant Status**:
The current state of a participant in the round. One of: `idle` (awaiting agent reply), `typing` (composing response), `submitted` (response sent), `ready` (acknowledged by hub), `disconnected`.
_Avoid_: State, phase, condition

### Transport

**Hub**:
The central message router that broadcasts messages between host, participants, and the agent. Provides typed channels for each message flow.
_Avoid_: Broker, router, bus, mediator

**Inbound Channel**:
Channel delivering messages from the hub to a TUI (host or participant).
_Avoid_: Input channel, receive channel

**Outbound Channel**:
Channel delivering messages from a TUI to the hub.
_Avoid_: Output channel, send channel

**Send Channel**:
Channel used by TUIs to explicitly send a message to the hub for broadcast.
_Avoid_: Publish channel, broadcast channel
